# Ascendant — Create: Applied Kinetics recipe fix

Correctif amovible pour les recettes fournies par `createappliedkinetics-1.5.4-1.21.1`.

Versions ciblées :

- Minecraft 1.21.1
- NeoForge 21.1.248
- Create 6.0.10
- Applied Energistics 2 19.2.17
- Create: Applied Kinetics 1.5.4-1.21.1

Le mod fournit 16 remplacements de recettes au format Forge/Create ancien. Ce datapack conserve les 11 séquences Create voulues et porte les cinq désactivations de recettes AE2 vers le format NeoForge 1.21.1.

Ce correctif suppose `overwrite_ae2_recipes = true`, valeur observée et valeur par défaut du mod. Si cette option doit être désactivée, retirer ce datapack ou ajouter des recettes AE2 de repli sous des IDs séparés.

Retrait : supprimer ce dossier de datapack après installation d'une version officiellement corrigée du mod, puis effectuer un redémarrage complet.
