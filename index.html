Ascendant

Minecraft 1.21.1 avec NeoForge

Télécharger le modpack pour Prism Launcher

Installation

  1. Installe et ouvre Prism Launcher.
  2. Clique sur Ajouter une instance, puis sur Importer.
  3. Choisis le fichier Ascendant-Prism.zip téléchargé ci-dessus.
  4. Clique sur OK, connecte ton compte Microsoft, puis lance Ascendant.

Le premier lancement télécharge le modpack. Les mises à jour suivantes sont vérifiées automatiquement avant chaque démarrage.
