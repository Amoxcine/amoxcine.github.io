Ascendant

Un pack coopératif d'exploration, de magie et d'industrie. Installe l'archive dans Prism Launcher : le premier démarrage récupère les fichiers du pack, puis Packwiz vérifie les mises à jour avant les lancements suivants.

Télécharger pour Prism Launcher

Version publique 1.0.0 · Java 21 requis

Installer le pack

L'archive est prévue pour Prism Launcher. Elle installe l'instance et contient la commande Packwiz nécessaire pour recevoir les futures mises à jour.

Installer Prism Launcher

Télécharge puis ouvre Prism Launcher. Connecte ensuite ton compte Microsoft dans Prism.

Importer l'archive

Dans Prism, choisis Ajouter une instance, puis Importer. Sélectionne Ascendant-Prism.zip.

Lancer Ascendant

Valide l'import puis démarre l'instance. Le premier lancement télécharge les fichiers ; laisse-le terminer avant de rejoindre le serveur.

Mettre à jour

Pour les joueurs

Ne télécharge pas une nouvelle archive à chaque mise à jour. Lance simplement l'instance : Packwiz compare le pack local à la version publiée et télécharge les fichiers modifiés.

En cas d'erreur

Ferme Prism, attends quelques minutes si une mise à jour vient d'être publiée, puis relance l'instance. Ne supprime pas des mods à la main : cela peut empêcher la connexion au serveur.

Avant de jouer

Le pack démarre avec des réglages graphiques équilibrés. Les shaders sont désactivés par défaut ; consulte le guide de performances seulement si ta machine montre des ralentissements. Le livre de quêtes en jeu reste le guide principal de progression.
